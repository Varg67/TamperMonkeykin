## 2024-05-24 - Unnecessary DOM writes in MutationObserver callbacks
**Learning:** In a cinematic RP extension that updates the UI frequently via `MutationObserver` (parsing JSON on text changes), writing to the DOM (like `node.textContent` or updating styles/classes of 10 UI blocks per stat) without checking if the value actually changed causes hundreds of unnecessary reflows/repaints per render cycle. Benchmarking showed ~390 unnecessary DOM property writes when re-rendering an unchanged state.
**Action:** Implement conditional DOM updates (DOM cache checking). Before setting `.textContent` or style properties, check if the value differs from the existing one. For grouped UI elements like the 10-block stat bars, hash the derived visual state (e.g., `filledBlocks-isDanger`) and only loop over the DOM nodes to update their classes and styles if this hash changes.
