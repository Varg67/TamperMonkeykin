## 2024-05-18 - [Preventing Layout Thrashing in MutationObservers]
**Learning:** Found a performance bottleneck in `cinematic-rp-extension-beta0.2.user.js` where a `MutationObserver` used `node.textContent || node.innerText || ""`. Accessing `innerText` forces a synchronous layout recalculation (reflow), which is extremely expensive when executed repeatedly on every added node. Furthermore, a heavy regex was being run on every text node.
**Action:** Removed the `innerText` fallback and introduced an early return fast-path (`if (!text.includes('"loc"')) return;`) to bypass the regex when the target keyword is absent. Always prefer `textContent` in observers to avoid layout thrashing, and use cheap string checks before expensive regex operations.
## 2024-06-05 - [DOM Write Caching to Prevent Redundant Reflows]
**Learning:** Found a performance bottleneck where `renderState` directly wrote to DOM attributes (`textContent`, `style.display`, `className`, and `style.backgroundColor`) on every update cycle, even when the data had not changed. Directly reading from `element.style` or updating identical strings forces unnecessary recalculations in the browser. Grouping the state of 10 UI blocks into a simple string hash (`${filledBlocks}-${isDanger}`) allows skipping the entire loop if the visual state hasn't altered.
**Action:** Implemented an in-memory caching system inside `domCache` for string values and block states. Before applying changes to the DOM, compare the new desired value against the cached JavaScript variable. If identical, skip the DOM API call entirely to drastically reduce redundant repaints and reflows.
